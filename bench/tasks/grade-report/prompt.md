Each line of standard input is a student's name followed by one or more
integer scores from 0 to 100, separated by spaces. Skip blank lines. For each
student, print `name average grade`, with the average of their scores to one
decimal place and a letter grade from the unrounded average: `A` for 90 or
more, `B` for 80 or more, `C` for 70 or more, `D` for 60 or more, otherwise
`F`. Order students by average descending, then by name. Finally print
`class average: X`, the mean of the students' averages to one decimal place.
If there are no students, print only `no students`.
